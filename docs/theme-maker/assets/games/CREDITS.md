# Sample game artwork

Theme Studio's preview library uses free homebrew games whose artwork is licensed for sharing. Thank you to their authors.

The `-shot.png` files are the games' own images, unchanged. The `-cover.jpg` files are covers made for Theme Studio from each game's own art (a console label and layout were added). They're shared under the same license as the game's art.
